# wuplac

Personal desktop workspace bundle.

This repository is used as a lightweight release channel for a small local Windows utility. It is not a public product, not a supported package, and not intended for general installation or redistribution.

## Status

Active personal build. Interfaces, file formats, and update assets may change without notice.

## Releases

Published release assets are meant for a specific local setup. If you do not already know what this repository is for, you probably do not need anything from it.

## Support

No public support is provided.
